# Vela POC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bootable Fedora Atomic image for the 2018 Mac mini that boots straight into a 4K Vela launcher, launches the real apps, shows real Jellyfin data, plays 4K, and controls TVs and IR devices. Everything that needs real hardware ships as an owner-run acceptance script.

**Architecture:** A pnpm TypeScript monorepo with three packages:
- `packages/shared`: the API types.
- `apps/daemon`: a Node service on `127.0.0.1:7300`. It owns app launching via Sway workspaces, Jellyfin, mpv playback, input, TVs via Home Assistant, and IR.
- `apps/launcher`: a Svelte web UI served by the daemon and shown in a kiosk Chromium window.

`os/` holds the bootc `Containerfile` and system files. GitHub Actions builds the image and boots it in a KVM VM at 3840x2160 for a smoke test.

**Tech Stack:**
- Node ≥ 22 (native type stripping), TypeScript 5+, pnpm workspaces, Vitest.
- Daemon: Fastify 5 with `@fastify/websocket` and `@fastify/static`, `zod`, `smol-toml`.
- Launcher: Svelte 5 + Vite.
- OS: Fedora bootc 44, t2linux kernel, RPM Fusion (ffmpeg, intel-media-driver), Sway, greetd, Chromium, mpv, `wtype`, `v4l-utils` (`ir-ctl`), Podman (Home Assistant), Flatpak.
- CI: GitHub Actions, bootc-image-builder.

**Spec:** `docs/superpowers/specs/2026-10-28-vela-design.md` (read it first). The visual reference is `spikes/2026-10-28-launcher/` and its `screenshots/`. Port the look, not the code.

## Global Constraints

**Display and assets**
- Display target: 3840x2160 at 60 Hz. Nothing is rendered below native 4K. Backdrops are requested at 3840 px wide; posters and cards at the device-pixel size they occupy on a 4K panel.
- 1 rem = `min(100vw / 120, 100vh / 67.5)`. The layout never reflows between 1080p and 4K.
- Palette (oklch): abyss `0.15 0.035 268`, nebula `0.28 0.07 285`, starlight `0.97 0.012 85`, plus the per-title `--tint`. No fixed accent.
- Fonts: Instrument Serif (titles) and Manrope (UI), bundled locally from `spikes/2026-10-28-launcher/assets/fonts/`. No runtime font or CDN requests.

**Copy**
- Sentence case. No all-caps labels. Errors say what happened and what to do, and never apologize.

**Daemon and system**
- The daemon listens on `127.0.0.1:7300` only.
- System config lives at `/etc/vela/vela.toml`, state at `/var/lib/vela/`, and secrets at `/var/lib/vela/secrets.json` (mode 0600). No secrets in the repo or the image.
- The session user is `vela`. Sway config is at `/usr/share/vela/sway/config`.
- No mouse cursor, window decorations, desktop, terminal, or notifications in normal use.

**Hardware facts**
- The builder has **no hardware access**. Every hardware check is an owner-run script under `scripts/acceptance/` that prints `PASS`/`FAIL` per check and writes `~/vela-report-<timestamp>.tar.gz`.
- Installing wipes the internal SSD (the owner chose this).
- Crunchyroll resolution is capped by Widevine L3. This is accepted; do not try to work around it.

**Licensing**
- Third-party art and data must have a license that allows redistribution. Record it in a `CREDITS.md` next to the asset.

## Review Focus

1. **The daemon isn't up yet, or restarts, when the launcher loads.** Expect the launcher to show the Vela backdrop and wordmark, retry quietly, and fill in when the daemon answers. Never a blank or error page. Test: Task 8, `api.test.ts`, "retries until the daemon answers".
2. **An app crashes or the user quits it.** Expect Vela to return to the home screen automatically. Never a black empty workspace. Test: Task 3, `appRunner.test.ts`, "returns home when the app's last window closes".
3. **The Jellyfin server is offline, or the token has expired.** Expect the Continue Watching row to be hidden and the home status line to read "Jellyfin isn't reachable. Check that the server is on." Apps keep working, and the daemon retries every 60 s. Test: Task 4, `homeState.test.ts`, "hides Jellyfin rows when the server is unreachable".
4. **An app isn't installed yet** (first boot, Flatpaks still downloading). Expect the tile to show "Installing" and Enter to show a "Plex is still installing" toast, not to spawn a broken command. Test: Task 3, `appRunner.test.ts`, "refuses to launch an app that is still installing".
5. **Arrows held down with key repeat.** Expect focus to move every repeat. The hero and backdrop update only after focus rests for 120 ms, with at most one crossfade in flight. Test: Task 8, `hero.test.ts`, "settles once after a burst of moves".

// sway.ts
export interface SwayWindow { id: number; appId: string | null; cls: string | null; workspace: string; pid: number }   // cls = window_properties.class (XWayland: Steam, possibly Plex HTPC/JMP)
export interface Sway {
  windows(): Promise<SwayWindow[]>;
  showWorkspace(name: string): Promise<void>;            // "home" | `app-${id}`
  onWindowClosed(cb: (w: SwayWindow) => void): () => void;
  onWindowNew(cb: (w: SwayWindow) => void): () => void;
}
export function createSway(): Sway;                       // uses `swaymsg -t get_tree -r` and `swaymsg -t subscribe -m '["window"]'`
// flatpak.ts
export function flatpakStatus(id: string, run?: (cmd: string[]) => Promise<string>): Promise<"ready" | "installing" | "missing">;
//   ready if `flatpak info <id>` succeeds; installing if /var/lib/vela/flatpak-installing contains the id; else missing
// appRunner.ts
export class AppRunner {
  constructor(deps: { sway: Sway; manifests: AppManifest[]; spawn: (cmd: string[], env: Record<string,string>) => { pid: number };
                      status: (m: AppManifest) => Promise<AppStatus>; emit: (e: VelaEvent) => void });
  launch(id: string): Promise<{ ok: true } | { ok: false; reason: "unknown" | "installing" | "missing" }>;
  goHome(): Promise<void>;          // shows workspace "home", emits {type:"home"}
  current(): string | "home";
}
```

- Behaviour:
  - `launch` switches to workspace `app-<id>`. If no window matches `windowAppId`, it spawns the app there: `swaymsg 'workspace app-<id>; exec <cmd>'`, or `spawn` with `assign` rules.
  - Already running: it only switches.
  - `builtin` apps (`home`) do not spawn; the launcher handles them.
  - When the last window of the current app closes, it calls `goHome()`.
  - If no matching window appears within 10 s of a spawn, it calls `goHome()` and emits the toast "Plex didn't start". The workspace switch happens when `onWindowNew` reports the matching window, not before; the launcher shows the launch screen meanwhile.
  - `vela-ctl` is POSIX `sh` using `curl`: `vela-ctl home | launch <id> | device <id> <command> | volume up|down|mute`. `volume` targets the device marked as `active TV`, which is the first `kind="tv"` device in config.

export interface JellyfinItem { id: string; name: string; year?: number; runTimeTicks?: number; positionTicks?: number;
  genres: string[]; overview?: string; hasBackdrop: boolean; hasPrimary: boolean; container?: string }
export class JellyfinClient {
  constructor(opts: { url: string; token?: string; userId?: string; fetch?: typeof fetch });
  authenticate(username: string, password: string): Promise<{ token: string; userId: string }>; // POST /Users/AuthenticateByName
  resume(limit?: number): Promise<JellyfinItem[]>;          // GET /UserItems/Resume?userId=…&limit=…&mediaTypes=Video
  imageUrl(itemId: string, type: "Backdrop" | "Primary", maxWidth: number): string; // upstream URL with tag + maxWidth
  streamUrl(itemId: string): string;                        // /Videos/{id}/stream?static=true&api_key=…
  reportStart(itemId: string, positionTicks: number): Promise<void>;     // POST /Sessions/Playing
  reportProgress(itemId: string, positionTicks: number, paused: boolean): Promise<void>; // POST /Sessions/Playing/Progress
  reportStopped(itemId: string, positionTicks: number): Promise<void>;   // POST /Sessions/Playing/Stopped
}
export function toCard(item: JellyfinItem): MediaCard;   // backdropUrl → "/api/art/jellyfin/<id>/Backdrop?w=3840"
// homeState.ts
export function buildHomeState(deps: { manifests: AppManifest[]; status: (m: AppManifest) => Promise<AppStatus>;

// mock.ts
export interface MockProvider { hero(slug: string): HeroItem; rows(): Row[] }
```

- **Art proxy:** `GET /api/art/jellyfin/:id/:type?w=` fetches upstream with the token and streams the bytes back with `Cache-Control: max-age=86400`. Allowed `w` values: 3840, 1280, 704. Anything else → 400.
- **Mock art:** fetch Blender open-movie images at **3840 px wide or wider** from Wikimedia Commons. Use one batched API call per size; Commons rate-limits per-file calls. Keep only files whose original width is ≥ 3840. Record the license and author in `CREDITS.md`. Exclude CC BY-SA if a CC BY alternative exists.
- **Rows:** "Continue watching" (wide) comes from Jellyfin resume when the provider is `jellyfin`, otherwise from mock. In POC mode the mock also supplies the spike's "Recently added" poster row. When the provider is `jellyfin` and it's unreachable, `rows` omits the Jellyfin rows and `status.line` = "Jellyfin isn't reachable. Check that the server is on."
