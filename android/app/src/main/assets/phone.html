Connections

Credentials are stored on the TV. A masked key keeps its saved value while its server address stays the same.

OpenAI compatible servers need the API base path, usually /v1. For Anthropic, leave the address blank for the official API.

Jellyfin, Plex & Home Assistant

All three Jellyfin fields are required to browse and save progress.

Optional: enter your own Plex server address and token. Plex home rows browse this server; selecting a title searches the installed Plex app. Search does not start or verify playback.

Your home screen
Ask Vela to arrange rows for you, or edit the layout here. Changes apply as soon as you save.









Household profiles


Profiles personalize Vela. They have no PIN authentication and do not secure other Android apps. Home rows and My list remain shared.






Profile preferences







Existing access restrictions and provider/library preferences are preserved. Child profiles stay restrictive; opaque app control may be unavailable. Use the TV for owner review.






Explicit memory


Only the exact words you Save are remembered. Never enter credentials. Sharing allows these words to be sent to your configured AI provider; memory is data and cannot grant permission.









Save explicit memory








Private export is shown only on your request. Save it somewhere you trust.




Durable routines


Routines submit normal tasks and may need approval. A busy TV queues them until their deadline. Android wakes are inexact. Saving binds a routine to the current profile and its exact policy/preferences. Later changes or a different active profile fail closed; edit and Save deliberately to rebind.






Routine editor




One-shot and interval schedules use a precise instant, including its UTC offset. They do not follow wall-clock changes.

External agent control


Disabled by default. Enabling creates a dedicated credential for an MCP listener on TV loopback (127.0.0.1:8766). Access from another computer requires an explicitly configured tunnel. This does not expose a LAN or public endpoint. External actions use the same restrictions and approvals.
